Myotus는 AE2의 **터미널 설정** 화면에 탭을 추가합니다. Myotus 관련 애드온도 이곳에 자체 설정을 추가할 수 있습니다.

## 업그레이드 패널 버튼

업그레이드 패널 버튼 옵션은 터미널 툴바에 Myotus 터미널 업그레이드 패널을 여는 버튼을 표시할지 제어합니다.

버튼을 끄는 것은 표시 설정일 뿐입니다. 터미널에 설치된 카드를 제거하지 않습니다.

## 뷰 셀 슬롯

**Minecraft 1.21.1**에서는 뷰 셀 옵션으로 Myotus 업그레이드 패널에 표시되는 AE2 뷰 셀 슬롯의 두 번째 열을 제어합니다.

**Minecraft 1.20.1**에서는 해당 옵션이 비활성화되어 있고 1.21.1 전용으로 표시됩니다. Forge 버전에 1.21.1 패널 레이아웃이 적용될 것이라고 기대하지 마세요.

## 터미널 키 바인딩

이 페이지의 설정은 Minecraft 키 매핑과 동기화됩니다. 기본값에서는 터미널을 열었을 때 터미널 전용 단축키가 작동합니다.

| 동작 | 키 매핑 ID |
| --- | --- |
| 터미널 설정 열기 | `key.myotus.open.terminal_setting` |
| 터미널 업그레이드 패널 전환 | `key.myotus.toggle.upgrade_terminal_panel` |

현재 자신의 설정에서 지정된 키를 사용하세요. 모드팩이나 플레이어가 키를 바꿀 수 있습니다.

## 최신 패널에 대한 참고

드래그 가능한 장비 패널과 터미널 모듈 API는 개발 중인 기능입니다. 이 페이지는 미커밋 기능이 아니라 공개 소스 스냅샷을 설명합니다.
